# 验收清单

本清单用于完整产品验收，不将模拟服务测试等同于真实 ComfyUI 验收。当前分项结果见 `verification.md`；下列未勾选项目仍需按完整场景验证。

## 基本连接

- [ ] 在 Win10 x64、Win11 x64 上各自验证自包含 EXE，不要求额外安装 .NET、SSH 客户端或 WSL。
- [ ] 从带空格和中文的目录启动程序，配置与日志正常保存。
- [ ] 粘贴普通 SSH 命令及自定义端口命令，解析结果正确且可以手工修改。
- [ ] 覆盖 `-p`、`-l`、`-i`、引用路径、参数顺序和 IPv6。
- [ ] 缺失值、端口越界、引号错误、重复参数、未知选项明确报错且不连接。
- [ ] 粘贴包含 shell 命令组合或远端命令的文本，不执行任何命令，也不修改已保存有效配置。
- [ ] 密码、私钥、加密私钥均可完成实际 SSH 认证；错误认证显示具体原因。
- [ ] 首次连接需要确认主机指纹；取消后不连接；保存后能匹配；指纹变化被阻止。
- [ ] 实际访问远端 ComfyUI 页面并验证 WebSocket 通信与一项受控操作；仅 TCP 连接成功不算通过。
- [ ] 修改目标地址后，可以通过宿主机访问测试容器内的 HTTP/WebSocket 服务。

## 端口与服务状态

- [x] ComfyUI 默认关闭，未开启时仅建立 SSH 会话，不创建本地监听、转发请求或 HTTP 探测。
- [x] 开关按 VPS 独立加密保存，旧版缺省字段按关闭处理。
- [x] 仅 SSH 模式在服务器主动断开后可自动恢复，且始终不显示本地服务地址。

- [ ] 自动端口模式在 `18188` 空闲时使用它，占用时绑定其他端口，显示正确地址。
- [ ] 固定端口被占用时提示错误，不静默换端口，不遗留 SSH 会话。
- [ ] 本地仅监听回环地址，局域网其他设备不能访问该监听。
- [ ] ComfyUI 未启动时提示目标不可达，不误报 SSH 认证失败，不反复重建健康隧道。
- [ ] 保持隧道，启动远端目标服务后能够访问；停止并重启目标后可再次访问。

## 恢复与取消

- [ ] 断网后检测失联，恢复网络后重连，保持原本地端口。
- [ ] 模拟丢弃流量而不正常关闭 TCP，验证半开连接能在限定时间内被识别。
- [ ] SSH 服务重启或测试服务器重启后自动恢复。
- [ ] Windows 睡眠唤醒、Wi-Fi 切换后重新检测并恢复。
- [ ] 初始连接时服务器不可用，按退避策略重试，服务器恢复后可连接。
- [ ] 连接中取消、重试等待中断开、唤醒同时断开，都不会随后自动连接。
- [ ] 连续点击连接/断开只产生一个有效连接流程，旧事件不能覆盖当前状态。
- [ ] 网络中断期间本地端口被占用，恢复时明确提示，不悄悄改变访问地址。
- [ ] 退出程序取消任务并释放端口，进程与连接没有残留。

## 界面和日常使用

- [ ] 首次连接、手动重连、自动重连成功均不自动打开浏览器。
- [ ] 仅点击「打开 ComfyUI」时打开已建立隧道对应的本地地址。
- [ ] 「复制地址」内容与实际监听一致；未建立隧道时相关按钮不可误用。
- [ ] 网络请求与重连期间窗口可操作，取消按钮及时生效。
- [ ] 关闭窗口进入托盘，重新打开可查看当前连接；托盘退出真正结束程序。
- [ ] 保存并重启后恢复配置，但不自动连接；点击一次即可发起连接。
- [ ] 中文界面在 100%、150%、200% 缩放下无关键内容遮挡；高级设置默认折叠。

## 数据与持续运行

- [x] 多个 VPS 配置可独立保存和切换；连接生命周期测试确认新会话开始前旧会话已停止。
- [x] 整份连接资料与主机指纹以 DPAPI 密文写入；名称、地址、用户名和密码不以明文出现在存储文件中。
- [x] 旧单配置及指纹 JSON 自动迁移，成功后移除旧明文文件；损坏密文不会静默覆盖。
- [x] 黑灰红主题、命令导入二级面板、ComfyUI 折叠设置已在当前 Windows 桌面检查。

- [ ] 未选择保存时，密码与私钥口令不落盘；选择保存后配置中不含明文。
- [ ] 日志与 UI 异常消息中不包含密码、私钥内容、私钥口令或完整原始命令。
- [ ] 配置写入中断或文件损坏时可提示处理，不静默丢失原配置。
- [ ] 执行至少 100 次受控断开/重连循环，连接数、监听端口、任务和句柄数不持续累积。
- [ ] 执行至少 24 小时持续运行，包含空闲、HTTP/WebSocket 流量和多次断网恢复，记录内存、句柄及失败次数。
- [ ] 日志文件与 UI 日志缓冲按上限截断或轮转，不无限增长。
