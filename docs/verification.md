## 自动测试：14 组通过

1. SSH 解析：引用路径、Windows 反斜杠、IPv6、参数顺序、未填用户名。
2. 拒绝 shell 表达式、未知/重复参数、错误端口、远端命令。
3. 配置与 DPAPI：加密回读、不写明文、取消保存凭据后移除密文。
4. 主机身份：拒绝首次确认、保存、匹配、变化阻止、损坏文件拒绝连接。
5. 生命周期：连接中取消、阻止并发启动、不在取消后复活。
6. 生命周期：失败进入退避，手动停止取消重试等待。
7. 真实 SSH 转发：HTTP、8 MiB 下载、2 MiB 上传、WebSocket 消息往返。
8. 真实 SSH 加密私钥认证。
9. 真实 SSH 错误密码归类为不可自动重试的认证失败。
10. 端口占用时自动分配；恢复时端口冲突不悄悄更换地址。
11. 目标 HTTP 服务关闭后保留 SSH；服务启动后原隧道恢复访问。
12. SSH 连接强制断开后控制器在原本地端口恢复；停止后端口释放。
13. 丢弃 TCP 流量而不关闭连接，通道建立超时触发失联检测。
14. 100 次真实连接/探测/释放循环，每次都可重新绑定本地端口。

测试服务：`tests/fixture/server.cjs`，仅监听回环地址，使用独立临时测试密钥、密码。未连接 GPU 实例。
